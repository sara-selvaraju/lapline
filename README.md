# Lapline

A phone-first second screen for F1 sessions: the circuit in 3D with every car, a timing tower, and telemetry for the car you pick, live or as a replay. A personal, non-commercial project built on OpenF1 data, hosted at lapline.live.

Lapline is unofficial and not affiliated with Formula 1. F1 and related marks are trademarks of Formula One Licensing B.V.

## Where things are

- `AGENTS.md` and `CLAUDE.md`: instructions for coding agents (Cursor and Claude Code).
- `docs/ARCHITECTURE.md`: how it's built, and why.
- `docs/BUILD-PLAN.md`: milestones M0 to M9.
- `docs/DESIGN.md` and `design/`: the design spec and the canvas sources.
- `docs/OPENF1.md`: notes on the data source.
- `reference/prototype/`: the working prototype the build starts from.
